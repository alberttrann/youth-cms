# FAQ Global Display Ordering Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let CMS editors reorder the shared FAQ list once with drag-and-drop, and render that order everywhere on the public site.

**Architecture:** Add a required `displayOrder` integer to the FAQ collection (mirrors the existing `team-member` pattern). A custom `POST /api/faqs/reorder` route assigns sequential order values to document IDs inside one `strapi.db.transaction`. A dedicated Strapi admin page (registered via `app.addMenuLink`) lists FAQs with native HTML5 drag-and-drop and submits the ordered ID array through `useFetchClient`. The frontend FAQ API changes its sort query from `createdAt:desc` to `displayOrder:asc`; response mapping is unchanged.

**Tech Stack:** Strapi 5.50.0 (Document Service API, `strapi.db.transaction`, explicit content-api route object), React admin app (`@strapi/strapi/admin` `useFetchClient` + `addMenuLink`), native HTML5 drag-and-drop (no new dependency), TypeScript, Vitest (frontend inline tests).

## Global Constraints

- Strapi `5.50.0`; Node `>=20`. No new npm dependencies (spec excludes adding one unless the existing admin runtime cannot support drag-drop — native HTML5 DnD covers it).
- `displayOrder` is `{ "type": "integer", "default": 0, "required": true }` — verbatim from the team-member schema precedent.
- Public read of `api::faq.faq.find` / `findOne` stays granted (already in `src/index.ts` `PUBLIC_READ_ACTIONS`); the reorder route must NOT be public.
- Follow existing patterns: `config.layouts` + `config.metadatas` in schema (team-member precedent), inline Vitest tests with `vi.stubGlobal('fetch')` (leadership.ts precedent).
- Commits: small, focused, one concern each.

- [ ] **Step 1: Add the reorder method**

Replace `src/api/faq/services/faq.ts` with:

```typescript
/**
 * faq service
 */

import { factories } from '@strapi/strapi';

export default factories.createCoreService('api::faq.faq', ({ strapi }) => ({
  /**
   * Assign sequential displayOrder values to the given FAQ document IDs,
   * in the order they appear in `documentIds`. Atomic: either all FAQs are
   * reordered or none are. Throws on invalid input.
   */
  async reorder(documentIds: string[]) {
    if (!Array.isArray(documentIds) || documentIds.length === 0) {
      throw new Error('Reorder requires a non-empty array of FAQ IDs');
    }

    const seen = new Set<string>();
    for (const id of documentIds) {
      if (typeof id !== 'string' || id.length === 0) {
        throw new Error('Each FAQ ID must be a non-empty string');
      }
      if (seen.has(id)) {
        throw new Error(`Duplicate FAQ ID in reorder request: ${id}`);
      }
      seen.add(id);
    }

    for (const id of documentIds) {
      const existing = await strapi.db.query('api::faq.faq').findOne({
        where: { documentId: id },
        select: ['documentId'],
      });
      if (!existing) {
        throw new Error(`Unknown FAQ ID: ${id}`);
      }
    }

    return strapi.db.transaction(async () => {
      const results: { documentId: string; displayOrder: number }[] = [];
      for (let i = 0; i < documentIds.length; i += 1) {
        const documentId = documentIds[i];
        await strapi.documents('api::faq.faq').update({
          documentId,
          data: { displayOrder: i + 1 },
        });
        results.push({ documentId, displayOrder: i + 1 });
      }
      return results;
    });
  },
}));
```

- [ ] **Step 1: Add the controller action**

Replace `src/api/faq/controllers/faq.ts` with:

```typescript
/**
 * faq controller
 */

import { factories } from '@strapi/strapi';

export default factories.createCoreController('api::faq.faq', ({ strapi }) => ({
  /**
   * POST /api/faqs/reorder — body: { ids: string[] }
   * Rewrites displayOrder for the given FAQ document IDs, in array order.
   */
  async reorder(ctx) {
    const { ids } = ctx.request.body as { ids?: unknown };

    if (!Array.isArray(ids)) {
      ctx.badRequest('Request body must include an "ids" array');
      return;
    }

    try {
      const updated = await strapi.service('api::faq.faq').reorder(ids as string[]);
      ctx.body = { data: updated };
    } catch (error) {
      ctx.badRequest((error as Error).message);
    }
  },
}));
```

- [ ] **Step 1: Create the page component**

Create `src/admin/extensions/pages/FaqOrderPage.tsx`:

```tsx
import { useCallback, useEffect, useState } from 'react';
import { useFetchClient } from '@strapi/strapi/admin';

interface FaqRow {
  id: number;
  documentId: string;
  question: string;
  answer: string;
  displayOrder: number;
}

interface FaqListResponse {
  data: FaqRow[];
}

interface ReorderResponse {
  data: { documentId: string; displayOrder: number }[];
}

export default function FaqOrderPage() {
  const [rows, setRows] = useState<FaqRow[]>([]);
  const [loading, setLoading] = useState(true);
  const [saving, setSaving] = useState(false);
  const [error, setError] = useState<string | null>(null);
  const [dragIndex, setDragIndex] = useState<number | null>(null);
  const { get, post } = useFetchClient();

  const loadFaqs = useCallback(async () => {
    setLoading(true);
    setError(null);
    try {
      const { data } = await get<FaqListResponse>(
        '/api/faqs?sort[0]=displayOrder:asc&pagination[pageSize]=100'
      );
      setRows(Array.isArray(data?.data) ? data.data : []);
    } catch (e) {
      setError(e instanceof Error ? e.message : 'Failed to load FAQs');
    } finally {
      setLoading(false);
    }
  }, [get]);

  useEffect(() => {
    loadFaqs();
  }, [loadFaqs]);

  const onDragStart = (index: number) => setDragIndex(index);
  const onDragOver = (e: React.DragEvent<HTMLLIElement>) => e.preventDefault();
  const onDrop = (index: number) => {
    if (dragIndex === null || dragIndex === index) {
      setDragIndex(null);
      return;
    }
    setRows((prev) => {
      const next = [...prev];
      const [moved] = next.splice(dragIndex, 1);
      next.splice(index, 0, moved);
      return next;
    });
    setDragIndex(null);
  };

  const save = async () => {
    setSaving(true);
    setError(null);
    const previousRows = rows;
    try {
      await post<ReorderResponse>('/api/faqs/reorder', {
        body: { ids: rows.map((r) => r.documentId) },
      });
      await loadFaqs();
    } catch (e) {
      setError(e instanceof Error ? e.message : 'Failed to save order');
      setRows(previousRows);
    } finally {
      setSaving(false);
    }
  };

  if (loading) return <p>Loading FAQs…</p>;

  return (
    <div style={{ padding: '24px', maxWidth: '720px' }}>
      <h1 style={{ fontSize: '20px', marginBottom: '16px' }}>FAQ Display Order</h1>
      <p style={{ marginBottom: '16px', color: '#666' }}>
        Drag rows to reorder. Click <strong>Save order</strong> to apply.
      </p>
      {error && (
        <p role="alert" style={{ color: '#d02b29', marginBottom: '12px' }}>
          {error}
        </p>
      )}
      <ul style={{ listStyle: 'none', padding: 0, margin: '0 0 16px 0' }}>
        {rows.map((row, index) => (
          <li
            key={row.documentId}
            draggable
            onDragStart={() => onDragStart(index)}
            onDragOver={onDragOver}
            onDrop={() => onDrop(index)}
            style={{
              padding: '12px 16px',
              border: '1px solid #dcdce4',
              borderRadius: '4px',
              marginBottom: '8px',
              cursor: 'grab',
              background: dragIndex === index ? '#e7f0ff' : '#fff',
            }}
          >
            <strong>{row.question || '(no question)'}</strong>
            <span style={{ color: '#888', marginLeft: '12px' }}>
              #{row.displayOrder}
            </span>
          </li>
        ))}
      </ul>
      <button
        type="button"
        onClick={save}
        disabled={saving || rows.length === 0}
        style={{
          background: '#1771B9',
          color: '#fff',
          border: 'none',
          padding: '8px 16px',
          borderRadius: '4px',
          cursor: saving ? 'wait' : 'pointer',
        }}
      >
        {saving ? 'Saving…' : 'Save order'}
      </button>
    </div>
  );
}
```
